# ФП Лаба 1 — Вариант 3: Робот на сетке

## Структура проекта

```
src/main/scala/
  monads/Monads.scala     — Блок 0: Monad, Reader, Writer, State, IO, Monoid
  domain/Domain.scala     — Блоки 1-3: типы, Reader/Writer/State функции
  scenario/Main.scala     — Блок 4: IO-сценарий, точка входа
```

## Запуск

```bash
sbt run
```

Требуется Java 11+ и sbt.

## Команды в интерактивном режиме

| Команда    | Действие                        |
|------------|---------------------------------|
| `up`       | Движение вверх                  |
| `down`     | Движение вниз                   |
| `left`     | Движение влево                  |
| `right`    | Движение вправо                 |
| `pick`     | Подобрать предмет на клетке     |
| `recharge` | Зарядить энергию до максимума   |
| `drop`     | Бросить последний предмет       |
| `exit`     | Выйти                           |

## Карта

```
. * . . .    (0,0) — старт робота R
. . . . .    * — предметы: ключ(1,0), монета(3,1), кристалл(0,4)
. . X . .    X — стены: (2,2) и (1,3)
. X . . .
* . . . .
```
